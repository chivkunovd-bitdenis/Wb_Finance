# Проверка макета на исходном фронте

Предыдущий вариант 425954b отклонён владельцем: он воспроизводил интерфейс отдельной разметкой и менял существующие элементы. Проверки того варианта не подтверждают соответствие текущему требованию.

## Границы исправленного варианта

Источник интерфейса — текущие компоненты приложения и их штатные стили. Разрешены только кнопка разворота/возврата дневной таблицы, её развёрнутый режим с сохранением меню и фон таблицы: WB светло-розовый, Ozon светло-голубой, с чередованием двух базовых и двух чуть более ярких дневных строк. Итоги, план-факт, остальные таблицы и элементы экрана не переоформляются.

Данные для просмотра синтетические. Макет не подтверждает расчёт финансов реального кабинета и не является выкатом в production.

## Результаты

Проверено во встроенном браузере на `http://127.0.0.1:5174/dashboard`. Исходный экран для сравнения — тот же адрес с `?baseline=1`: те же компоненты и данные, добавки выключены.

При 1280×900 сравнивались геометрия, шрифт и padding 11 групп узлов: меню, верхняя панель, content, KPI, график, карточки таблиц, шапки, заголовки, настройки колонок, счётчики дней, области прокрутки. WB: различий нет. Ozon: все размеры и позиции блоков совпадают; вертикальная координата счётчика дней отличается на 0.0078125 px из-за дробного округления flex-выравнивания. Предварительный сдвиг высоты заголовка на 0.6 px устранён уменьшением только новой кнопки.

WB дневные строки чередуются парами `#fff9fc / #fff3f8`, Ozon — `#f7fbff / #edf6ff`. Проверены первые восемь строк: A,A,B,B,A,A,B,B. При включении штатного план-факта WB окрашены 11 дневных строк; разделитель месяца, ИТОГО и все плановые строки не получают полос. Штатное наведение восстановлено точечным правилом для окрашенных ячеек.

Развёрнутый WB при 1280×900 занимает x=220, y=0, ширину 1060 и высоту 900; Ozon также покрывает область справа от меню. Возврат по Escape и кнопке проверен, фокус возвращается на «Развернуть таблицу». В узком окне 390×700 WB сохраняет исходное меню 220 px и таблицу 170×700, новая кнопка остаётся в пределах x=321…341. Ozon сохраняет штатную верхнюю навигацию высотой 54 px, таблица занимает x=0,y=54,390×646; кнопка также доступна. Временные размеры окна сброшены.

Консоль браузера исправленного макета: ошибок нет. Независимое read-only ревью Luna xhigh подтвердило область изменений, API alias и изоляцию хранилища. Целевой ESLint, отдельная Vite-сборка и `git diff --check` успешны. Сборочная папка не включается в Git.

`frontend/src`, production `frontend/dist`, основной Vite config и package manifests не изменены. Запущен только отдельный локальный prototype Vite без proxy; текущие API imports подменены локальными fixtures. Хранилище провайдеров работает в памяти страницы. Неиспользуемые действия отклоняются локально; этот просмотр не предназначен для работы с другими разделами или настоящими кабинетами.

Во время замены файлов старый dev-сервер 5173 успел подхватить промежуточный entry через HMR до появления отдельного config и попытался обратиться к localhost:8000. Все обращения завершились ECONNREFUSED, сервер 5173 остановлен. Дальнейшая проверка проведена только после независимой проверки fixture alias на 5174. Постоянное localStorage промежуточный entry не изменял.

## Восстановление просмотра

Из `frontend` выполнить `npx vite --config prototypes/table-expand/vite.config.js` и открыть `http://127.0.0.1:5174/dashboard`. Сборка: `npx vite build --config prototypes/table-expand/vite.config.js`. Снимки исправленного интерфейса находятся в `screenshots/`; `wb-baseline.jpg` показывает исходный экран без добавок.

# Бот поддержки клиентов WB Finance

## Что это и зачем

Это бот, которого добавляют в групповые чаты с клиентами вместе с сотрудниками. Сам бот ничего не отвечает. Он получает каждое сообщение и записывает его в локальную базу (файл SQLite, в нём хранятся переписка и служебные данные). Бот опрашивает Telegram сам, так называемым long polling: Mac не имеет публичного адреса, поэтому Telegram сам бот не вызывает.

Отдельная команда watch ждёт новое сообщение клиента и завершается, напечатав его текст. Это сигнал для живой сессии Claude Code, которая работает в фоне: сессия читает сообщение, смотрит код и данные wb-finance и отвечает клиенту через команду send. Ответы сессии должны быть вежливыми, деловыми и без технических подробностей. Правила для сессии записаны в docs/support-bot/SESSION_RULES.md.

Важно: этот бот полностью независим от других проектов. Он не читает и не использует никакие файлы вне этой папки и папки ~/.wbf-support-bot.

## Что нужно сделать владельцу один раз

1. Создайте бота в @BotFather командой /newbot. Дайте ему собственное имя, например «WB Finance support bot». BotFather выдаст токен. Токен запишите только в config.json, больше нигде.
2. В @BotFather отправьте /setprivacy, выберите этого бота и выберите Disable. Без этого бот не увидит обычные сообщения в группах: режим приватности по умолчанию пропускает только команды.
3. Если бот уже состоял в группе до смены режима приватности, удалите его из группы и добавьте заново. Telegram применяет новый режим только при добавлении.
4. Добавьте бота в каждый клиентский чат.
5. Запустите установку из папки tools/support_bot: `launchd/install.sh`. Скрипт создаст папку ~/.wbf-support-bot с правами 700, своё окружение Python, файл config.json из шаблона с правами 600 и проверит его. Если поля не заполнены, он перечислит их и остановится. Автозапуск при этом не включается, так что сервис не будет перезапускаться по кругу.
6. Откройте ~/.wbf-support-bot/config.json и заполните поля:
   - bot_token: токен из BotFather;
   - owner_user_id: ваш числовой Telegram id. Узнать его можно у любого бота, который показывает id, либо в выводе команды show после вашего сообщения в группе (поле «Автор ... (id ...)»);
   - internal_user_ids: id сотрудников, чьи сообщения не считаются клиентскими (их бот записывает, но watch их не показывает);
   - chats: id групп с названиями клиентов, см. пункт 7;
   - openai_api_key: необязательный ключ OpenAI для расшифровки голосовых. Без него голосовые сохраняются с пометкой «без расшифровки».
7. Выполните `python3 -m wbf_support_bot chats`. Команда покажет id групп, в которых бот уже видел сообщения. Id групп отрицательные, например -1001234567890. Перенесите нужные id в chats:

   ```
   "chats": {
     "-1001234567890": {"client": "Название клиента"}
   }
   ```

8. Запустите install.sh ещё раз. Он проверит конфиг, включит автозапуск и перезапустит сервис.

## Команды

Все команды запускаются из папки tools/support_bot. Путь к конфигу можно не указывать: по умолчанию берётся ~/.wbf-support-bot/config.json. Другой путь задаётся параметром --config (до или после команды) или переменной WBF_SUPPORT_BOT_CONFIG.

```
python3 -m wbf_support_bot check-config     # проверить config.json без сети
python3 -m wbf_support_bot check            # проверить связь с Telegram (getMe)
python3 -m wbf_support_bot chats            # группы, которые видел бот
python3 -m wbf_support_bot run              # опрос Telegram; запускает launchd постоянно
python3 -m wbf_support_bot watch            # ждать новых клиентских сообщений
python3 -m wbf_support_bot history --chat -1001234567890 --limit 20
python3 -m wbf_support_bot show --id 45     # полный текст сообщения
python3 -m wbf_support_bot download --id 45 --out ~/Desktop/акт.pdf
python3 -m wbf_support_bot send --chat -1001234567890 --reply-to 812 --key ответ-2026-10-22-1 --text -
```

Пояснения:

- run работает постоянно. Его запускает launchd, вручную обычно не нужен.
- watch молчит, пока не появится новое сообщение клиента. Потом он подождёт 45 секунд тишины, чтобы собрать несколько сообщений в один вывод, напечатает их и завершится с кодом 0. Если сообщений нет два часа, он напечатает «тишина» и тоже завершится. Если бот перестал записывать сообщения (больше 3 минут нет признаков жизни), watch напечатает «БОТ НЕ ЗАПУЩЕН» и завершится с кодом 1. Если мы пообещали клиенту ответ («разбираемся», «проверим», «напишу», «вернусь», «уточню») и больше часа ничего не отправили, watch напечатает напоминание. Каждое напоминание печатается один раз.
- При первом запуске watch считает уже существующие сообщения прочитанными и ждёт только новых. Старые сообщения смотрите через history.
- send отправляет текст в клиентский чат из config или в ваш личный чат с ботом. Текст можно передать через stdin: параметр `--text -` и текст в следующих строках (так удобно для многострочных ответов). Длинный текст бот делит на части по абзацам, а файл отправляет через `--file`.
- send устроен так, что одно и то же сообщение не уйдёт дважды. У каждого ответа должен быть свой уникальный ключ `--key`. Если отправка с этим ключом уже прошла, команда ничего не отправляет и показывает результат. Если предыдущая попытка оборвалась на неизвестном этапе (статус unknown или sending), команда тоже ничего не отправляет и предупреждает: сообщение могло уйти. Тогда проверьте чат вручную. Код выхода: 0 — отправлено, 1 — отклонено или не ушло, 3 — неизвестно, не повторять.

## Безопасность

- Токен и ключ OpenAI хранятся только в config.json (права 600). В логах и на экране они маскируются, команда check-config показывает только последние символы.
- В клиентские чаты send пишет только те, что перечислены в config, и ваш личный чат. Все остальные адреса он отклоняет.
- Переписка и служебные данные лежат в ~/.wbf-support-bot/state.db, а не в репозитории. Файлы состояния и config.json в .gitignore на случай, если кто-то укажет папку внутри репозитория.
- Установка трогает только метку launchd pro.wbfinance.support-bot, папку ~/.wbf-support-bot, свой plist и свой лог. Другие сервисы и папки она не читает и не меняет, файлы ничего не удаляет.

## Остановка, обновление, удаление

- Остановить: `launchctl bootout gui/$(id -u)/pro.wbfinance.support-bot`
- Запустить снова: `launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/pro.wbfinance.support-bot.plist`
- Обновить код: после изменений в репозитории снова запустите `launchd/install.sh`. Конфиг и база сохранятся, файлы пакета обновятся.
- Удалить: остановить сервис, удалить ~/Library/LaunchAgents/pro.wbfinance.support-bot.plist. Папку ~/.wbf-support-bot удаляйте только осознанно: вместе с ней пропадёт вся переписка.
- Логи: ~/Library/Logs/wbf-support-bot.log. Если watch говорит «БОТ НЕ ЗАПУЩЕН», начните с этого файла и с команды `launchctl print gui/$(id -u)/pro.wbfinance.support-bot`.
- Ошибка «конфликт 409» в логе означает, что два процесса опрашивают один и тот же токен. Оставьте один.

## Тесты

Тесты работают без сети: Telegram и OpenAI подменены фейками.

```
cd tools/support_bot
python3 -m pytest -q
ruff check .
```

## Ограничения

- Голосовые расшифровываются только при наличии ключа OpenAI. Расшифровка повторяется до трёх раз, потом помечается как неудачная.
- Telegram не отдаёт боту файлы больше 20 МБ.
- Бот видит только сообщения групп, где режим приватности выключен и бот добавлен заново после этого.
- Правки сообщений сохраняются поверх старого текста, история правок не ведётся.

## Файлы папки

- wbf_support_bot — код пакета (конфиг, база, опрос Telegram, watch, send, команды).
- tests — тесты с фейками.
- config.example.json — шаблон конфига без секретов.
- launchd — шаблон сервиса launchd и скрипт установки install.sh.
